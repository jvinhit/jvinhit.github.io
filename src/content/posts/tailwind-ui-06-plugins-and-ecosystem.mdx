Bạn dựng được gần như mọi thứ với utility lõi. **Plugin** thêm các gói utility chuyên dụng cho nhu cầu phổ biến, và v4 cho bạn tự viết utility/variant ngay trong CSS. Phần này nói về ba plugin bạn sẽ cài trong hầu hết project, cùng các primitive mở rộng của v4.

---

## 1. Cách nạp plugin ở v4

Ở v4 bạn nạp plugin từ **CSS** bằng `@plugin`, không phải từ config JS:

```css
@import "tailwindcss";

@plugin "@tailwindcss/typography";
@plugin "@tailwindcss/forms";
```

Đó là toàn bộ phần ghép nối. So sánh trước/sau của từng plugin trong showcase bên dưới:

## 2. `@tailwindcss/typography` — class `prose`

Khi bạn render nội dung **không kiểm soát từng phần tử** — Markdown, MDX, CMS — bạn không thể gắn utility lên từng thẻ. Class `prose` style cả cây con với mặc định typography hợp lý:

```bash
npm install -D @tailwindcss/typography
```

```html
<article class="prose lg:prose-xl dark:prose-invert">
  <!-- raw HTML from Markdown: h1..h6, p, ul, blockquote, code, img… -->
</article>
```

Các bộ chỉnh: `prose-sm`…`prose-xl` ... và override theo phần tử như `prose-headings:font-display` hay `prose-a:text-indigo-500`. Đây là thứ style phần thân của hầu hết bài blog.

---

## 3. `@tailwindcss/forms` — control form tử tế

Control form gốc render khác nhau giữa các trình duyệt và khó style. Plugin này cho chúng một **nền thân thiện với utility** để `border-*`, `rounded-*`, `focus:ring-*` hoạt động đúng kỳ vọng:

```bash
npm install -D @tailwindcss/forms
```

```html
<input
  type="email"
  class="w-full rounded-lg border-slate-300 focus:border-indigo-500 focus:ring-indigo-500"
/>
```

Không có nó, style một `<select>` hay checkbox cho khớp thiết kế là cực hình. Có nó, chúng hành xử như mọi phần tử khác.

## 4. Utility animation — `tw-animate-css`

Component shadcn animate bằng utility enter/exit — `animate-in`, `fade-in`, `zoom-in-95`, `slide-in-from-bottom-2`, kết hợp với `data-[state]`. Ở thời v4 chúng đến từ **`tw-animate-css`** (kế thừa `tailwindcss-animate` vốn cho v3):

```bash
npm install -D tw-animate-css
```

```css
@import "tailwindcss";
@import "tw-animate-css";
```

```html
<!-- A dialog content that animates open/closed via Radix's data-state -->
<div
  class="data-[state=open]:animate-in data-[state=open]:fade-in-0 data-[state=open]:zoom-in-95
         data-[state=closed]:animate-out data-[state=closed]:fade-out-0 data-[state=closed]:zoom-out-95"
>
  …
</div>
```

Bạn sẽ thấy đúng mẫu này khi ta ghép dialog của Radix và shadcn (Phần 7–9).

## 5. Tự viết utility — `@utility`

v4 đưa custom utility thành công dân hạng nhất trong CSS. Định nghĩa một cái và nó tham gia variant (`hover:`, `md:`) như mọi utility có sẵn:

```css
/* a reusable text-balance utility */
@utility text-balance {
  text-wrap: balance;
}

/* a tap-highlight reset */
@utility tap-transparent {
  -webkit-tap-highlight-color: transparent;
}
```

```html
<h1 class="text-balance md:text-balance">…</h1>
```

## 6. Tự viết variant — `@custom-variant`

Ta đã dùng cái này cho dark mode ở Phần 3. Dạng tổng quát cho bạn phát minh bất kỳ tiền tố trạng thái nào:

```css
/* style when a parent/self has aria-current="page" */
@custom-variant current (&[aria-current="page"]);

/* style when inside a [data-theme="brand"] scope */
@custom-variant brand (&:where([data-theme="brand"] *));
```

```html
<a class="text-slate-500 current:text-indigo-500" aria-current="page">Home</a>
```

Đây là cách giữ các trạng thái riêng của app (`aria-*`, `data-*` tùy biến) khai báo thay vì rẽ nhánh trong JS.

## 7. Phần còn lại của bộ đồ nghề pro

- tự sắp xếp tên class theo thứ tự chuẩn; chấm dứt mọi tranh cãi "đặt class này ở đâu".
- cảnh báo class xung đột/không hợp lệ.
- hiếm cần vì `aspect-*` đã vào lõi, nhưng vẫn có cho legacy.

Cài plugin Prettier ngay đầu tiên ở mọi project nhóm — thứ tự class nhất quán làm diff và review dễ chịu hơn nhiều.

## 8. Bài tập

**1.** Nạp plugin typography ở v4 và render một bài Markdown bằng `prose` đảo màu khi dark mode.

<details>
<summary>Lời giải</summary>

```css
@plugin "@tailwindcss/typography";
```
```html
<article class="prose dark:prose-invert">…</article>
```
</details>

**2.** Viết một `@utility` tên `text-pretty` đặt `text-wrap: pretty`.

<details>
<summary>Lời giải</summary>

```css
@utility text-pretty { text-wrap: pretty; }
```
</details>

**3.** Tạo `@custom-variant` tên `expanded` áp khi phần tử có `aria-expanded="true"`.

<details>
<summary>Lời giải</summary>

```css
@custom-variant expanded (&[aria-expanded="true"]);
```
```html
<button class="expanded:bg-indigo-500" aria-expanded="true">…</button>
```
</details>

Nâng cao:trong tab animate, xác định hai utility tạo hiệu ứng "bật" của dialog shadcn: một fade cộng một zoom nhẹ.

## Điểm chính

- v4 nạp plugin từ CSS qua `@plugin` — không cần config JS.
- `typography` style nội dung không gắn class được; `forms` làm input thân thiện utility; `tw-animate-css` cấp motion enter/exit cho shadcn.
- v4 cho bạn tự viết utility (`@utility`) và variant (`@custom-variant`) trong CSS.
- Thêm **plugin Tailwind của Prettier** để tự sắp xếp class nhất quán.
