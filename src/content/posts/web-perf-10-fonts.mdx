Web font là con dao hai lưỡi: chúng làm trang đẹp và đúng thương hiệu, nhưng nếu xử lý sai sẽ gây **text vô hình** (FOIT) làm chậm LCP, hoặc **text nhảy** (FOUT) gây CLS. Phần này gom chiến lược nạp font để có cả tốc độ lẫn ổn định.

---

## 1. Vấn đề: FOIT và FOUT

Khi trang dùng font tùy chỉnh chưa tải xong, trình duyệt phải chọn:

- **FOIT (Flash of Invisible Text)**: ẩn text tới khi font về → người dùng thấy khoảng trống → **chậm LCP/FCP** nếu text là nội dung chính.
- **FOUT (Flash of Unstyled Text)**: hiện ngay bằng font hệ thống, đổi sang font tùy chỉnh khi về → text "nhảy" kích thước → **CLS**.

Mục tiêu: hiện text *sớm* (tránh FOIT) mà *không nhảy* (tránh CLS). Đạt được bằng kết hợp `font-display` + preload + `size-adjust`.

---

## 2. Format: chỉ cần woff2

`woff2` nén tốt nhất và được hỗ trợ rộng khắp. Bỏ các format cũ (ttf, eot, woff) trừ khi phải hỗ trợ trình duyệt rất cũ — chúng chỉ làm nặng thêm.

```css
@font-face {
  font-family: 'Inter';
  src: url('/fonts/inter.woff2') format('woff2'); /* woff2 alone is enough */
  font-weight: 100 900; /* variable font: one file for every weight */
  font-display: swap;
}
```

> **Variable font** gói nhiều weight/độ rộng vào một file — thường nhẹ hơn tải nhiều file weight riêng, nếu bạn dùng từ 2–3 weight trở lên.

---

## 3. `font-display`: kiểm soát hành vi swap

`font-display` quyết định trình duyệt hành xử ra sao khi font đang tải:

| Giá trị | Hành vi | Đánh đổi |
|---------|---------|----------|
| `swap` | hiện fallback ngay, đổi khi font về | nhanh hiện text, nhưng có thể FOUT/CLS |
| `optional` | dùng font nếu về *rất nhanh*, không thì giữ fallback | tốt nhất cho CLS, font có thể không hiện lần đầu |
| `fallback` | thỏa hiệp giữa swap và optional | cân bằng |
| `block` | ẩn text ngắn rồi mới hiện | gần như FOIT, tránh dùng cho nội dung |

Khuyến nghị: **`swap`** cho hầu hết trường hợp (ưu tiên hiện text), kết hợp `size-adjust` (mục 5) để khử CLS. Dùng **`optional`** nếu bạn ưu tiên zero-CLS tuyệt đối và chấp nhận font đôi khi không hiện ở lần tải đầu.

---

## 4. Preload font critical

Font khai trong CSS bị phát hiện muộn (trình duyệt phải tải + parse CSS mới biết cần font). `preload` font dùng cho above-the-fold để nó tải sớm song song:

```html
<!-- preload critical font: crossorigin REQUIRED for fonts (even self-hosted) -->
<link rel="preload" href="/fonts/inter.woff2" as="font" type="font/woff2" crossorigin />
```

Lưu ý hai điều: chỉ preload **1–2 font thật sự dùng ngay** (preload nhiều sẽ cạnh tranh băng thông với LCP — Phần 4), và **luôn có `crossorigin`** cho font (font được fetch ở chế độ CORS, thiếu nó sẽ tải hai lần).

---

## 5. `size-adjust`: khử CLS khi swap

Đây là kỹ thuật quan trọng nhất để dùng `font-display: swap` mà không bị CLS. Ý tưởng: tạo một `@font-face` fallback từ font hệ thống, tinh chỉnh metric để nó **chiếm đúng không gian** như font tùy chỉnh — nên khi swap, chữ không đổi kích thước.

```css
/* Fallback metrics match Inter → swap does not shift layout */
@font-face {
  font-family: 'Inter Fallback';
  src: local('Arial');
  size-adjust: 107%;
  ascent-override: 90%;
  descent-override: 22%;
  line-gap-override: 0%;
}

body {
  font-family: 'Inter', 'Inter Fallback', sans-serif; /* fallback sits in the middle */
}
```

> Các con số (`size-adjust`, `ascent-override`...) tính được bằng công cụ như `fontaine` hoặc Next.js `next/font` (tự sinh fallback khớp metric). Đây là cách hòa giải mâu thuẫn "hiện sớm" (swap) và "không nhảy" (CLS) đã nêu ở Phần 7.

---

## 6. Self-host thay vì Google Fonts CDN

Trước đây nhúng `<link>` Google Fonts tiện, nhưng self-host thường nhanh hơn:

- **Bớt một kết nối** tới origin khác (fonts.googleapis.com + fonts.gstatic.com → 2 lần bắt tay).
- **Kiểm soát caching** và preload tốt hơn.
- **Riêng tư** hơn (không gọi sang Google).

Nếu vẫn dùng CDN font, tối thiểu hãy `preconnect` sớm (Phần 4):

```html
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
```

---

## 7. Subsetting: chỉ nạp ký tự cần

Font đầy đủ chứa hàng nghìn glyph cho nhiều ngôn ngữ. Nếu trang chỉ dùng Latin + tiếng Việt, **subset** font để bỏ glyph thừa, giảm dung lượng đáng kể:

- Dùng `unicode-range` để trình duyệt chỉ tải subset khi trang thật sự dùng ký tự đó:

```css
@font-face {
  font-family: 'Inter';
  src: url('/fonts/inter-vietnamese.woff2') format('woff2');
  unicode-range: U+0102-0103, U+0110-0111, U+1EA0-1EF9, U+20AB; /* Vietnamese range */
}
```

- Hoặc subset lúc build bằng `glyphhanger`/`subset-font` để tạo file chỉ chứa ký tự dùng.

> Với tiếng Việt, đảm bảo subset bao phủ đủ các nguyên âm có dấu và "đ/Đ" — thiếu sẽ khiến một số chữ rớt về font hệ thống (lệch hình).

---

## 8. Checklist fonts

1. Chỉ dùng **woff2** (cân nhắc variable font)?
2. **`font-display: swap`** (hoặc `optional` nếu ưu tiên zero-CLS)?
3. **Preload** 1–2 font critical với **`crossorigin`**?
4. Có **fallback khớp metric** (`size-adjust`) để swap không nhảy?
5. **Self-host** hoặc ít nhất **preconnect** CDN font?
6. **Subset** theo ngôn ngữ thật sự dùng (đủ tiếng Việt)?

---

## Tóm tắt

- Font sai gây **FOIT** (chậm LCP) hoặc **FOUT** (CLS); mục tiêu: hiện sớm mà không nhảy.
- Dùng **woff2** (variable font khi nhiều weight); **`font-display: swap`** mặc định.
- **Preload** font critical (kèm `crossorigin`), nhưng đừng preload quá nhiều.
- **`size-adjust`** cho fallback khớp metric để khử CLS lúc swap.
- **Self-host** + **subset** theo ngôn ngữ (đủ tiếng Việt) để giảm byte và lượt kết nối.

**Phần tiếp theo:** Network & caching — HTTP cache, CDN, nén, HTTP/2-3 và service worker.
