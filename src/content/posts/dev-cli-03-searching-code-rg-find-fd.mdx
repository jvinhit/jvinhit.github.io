Đây là **Phần 3**. Developer sống trong codebase lớn sẽ hỏi cùng một nhóm câu hỏi:

- Hàm này được gọi ở đâu?
- Config này nằm file nào?
- Có bao nhiêu TODO còn lại?
- Tên env var này xuất hiện ở đâu?
- File nào mới sửa gần đây?

Editor có search tốt, nhưng terminal search giúp bạn ghép với pipe, script, CI và automation.

---

## Dùng `rg` trước

`rg` là `ripgrep`, công cụ search rất nhanh và mặc định hợp với codebase: nó tôn trọng `.gitignore`, bỏ qua thư mục nặng, và in output dễ đọc.

```bash
rg "useEffect"
rg "process.env"
rg "TODO"
```

Search không phân biệt hoa thường:

```bash
rg -i "authorization"
```

In số dòng:

```bash
rg -n "fetch\\("
```

Chỉ in tên file match:

```bash
rg -l "getServerSideProps"
```

Đếm match theo file:

```bash
rg -c "TODO"
```

## Context lines: đọc quanh match

Một dòng match thường chưa đủ. Thêm context:

```bash
rg -C 3 "throw new Error"
rg -A 5 "function parse"
rg -B 5 "return null"
```

| Flag   | Nghĩa               |
| ------ | ------------------- |
| `-C 3` | 3 dòng trước và sau |
| `-A 5` | 5 dòng sau          |
| `-B 5` | 5 dòng trước        |

Khi review code bằng terminal, `rg -C` thường nhanh hơn mở từng file.

## Glob và exclude

Chỉ tìm trong TypeScript:

```bash
rg "createClient" -g '*.ts' -g '*.tsx'
```

Bỏ qua test:

```bash
rg "localStorage" -g '!*.test.ts' -g '!*.spec.ts'
```

Bỏ qua thư mục:

```bash
rg "apiKey" -g '!dist/**' -g '!coverage/**'
```

Tìm trong cả file bị ignore:

```bash
rg --hidden --glob '!.git/**' "MY_ENV_VAR"
```

`--hidden` sẽ đọc dotfile như `.env.example`, `.github/workflows`, `.npmrc`. Luôn exclude `.git/**` nếu bạn không muốn search vào object database của Git.

## `rg --files`: liệt kê file theo ignore rules

Đôi khi bạn không cần tìm nội dung, chỉ cần danh sách file:

```bash
rg --files
rg --files | rg 'package.json|tsconfig.json|vite.config'
rg --files src/content/posts | rg 'bash-|docker-'
```

Đếm số MDX posts:

```bash
rg --files src/content/posts | rg '\\.mdx$' | wc -l
```

Đây là combo rất nhanh: `rg --files` tạo danh sách file, pipe sang `rg` thứ hai để lọc tên.

## `find`: tìm file theo thuộc tính

`find` có sẵn gần như mọi nơi.

```bash
find . -name '*.log'
find src -type f -name '*.ts'
find . -type d -name node_modules
```

Tìm file mới sửa trong 24 giờ:

```bash
find . -type f -mtime -1
```

Tìm file lớn hơn 5MB:

```bash
find . -type f -size +5M -print
```

Tìm và xóa file tạm, nhưng hãy dry-run trước:

```bash
find . -name '*.tmp' -print
find . -name '*.tmp' -delete
```

`-delete` là thao tác thật. Luôn chạy bản `-print` trước.

---

## `fd`: find thân thiện hơn

Nếu có thể cài thêm, `fd` là phiên bản dễ dùng hơn của `find`.

```bash
fd package.json
fd -e mdx
fd bash src/content/posts
fd -H '^\\.env'
```

| Nhu cầu                | `find`              | `fd`           |
| ---------------------- | ------------------- | -------------- |
| Có sẵn mặc định        | Rất cao             | Thường cần cài |
| Cú pháp                | Dài                 | Ngắn           |
| Tôn trọng `.gitignore` | Không mặc định      | Có             |
| Search hidden          | Cần điều kiện riêng | `-H`           |

Nếu repo/team chưa dùng `fd`, cứ dùng `find`. Nếu máy cá nhân của bạn có `fd`, nó làm việc hàng ngày rất sướng.

## Null separator: xử lý tên file có space

Tên file có space làm vỡ pipeline kiểu cũ:

```bash
find . -name '*.mdx' | xargs wc -l
```

An toàn hơn:

```bash
find . -name '*.mdx' -print0 | xargs -0 wc -l
```

Với `rg`:

```bash
rg -l --null "TODO" | xargs -0 sed -n '1,20p'
```

Quy tắc: khi output là danh sách file đưa sang lệnh khác, ưu tiên `-print0` và `xargs -0`.

## Recipe developer hay dùng

Tìm mọi nơi dùng một env var:

```bash
rg --hidden --glob '!.git/**' "OPENAI_API_KEY|DATABASE_URL"
```

Tìm route hoặc page:

```bash
rg --files src/pages | sort
```

Tìm import từ package cụ thể:

```bash
rg "from ['\\\"]@tanstack/react-query['\\\"]" src
```

Tìm TODO/FIXME có context:

```bash
rg -n -C 2 "TODO|FIXME|HACK" src
```

Tìm file config ở root và cấp 2:

```bash
find . -maxdepth 2 -type f \\( -name '*config*' -o -name '.*rc' -o -name '*.json' \\) -print
```

## Điều cốt lõi

Dùng `rg` để tìm **nội dung**, `rg --files` hoặc `find/fd` để tìm **file**, và dùng glob/exclude để giữ kết quả nhỏ. Search tốt là kỹ năng đọc codebase nhanh, không chỉ là tiện ích terminal.
