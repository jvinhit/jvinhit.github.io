Phần 1 giới thiệu **cây accessibility** — mỗi node phơi **role**, **name**, **state**, và **value** cho công nghệ hỗ trợ. Với ảnh, icon, và control không chữ hiển thị, **tên accessible** thường là *thông tin duy nhất* người dùng screen reader nhận được. Sai tên — hoặc thiếu tên — và UI thành một bức tường "button", "image", "link".

Phần này giải thích cách tính tên, viết alt text, và xử lý ảnh trang trí, nút icon, SVG, và hình ảnh phức tạp như biểu đồ.

---

## 1. Cách tính tên accessible

Trình duyệt theo thuật toán **Accessible Name and Description Computation** (accname) — stack ưu tiên, không phải "cái nào trông gần nhất". Với hầu hết phần tử, ưu tiên đơn giản hóa:

```text
1. aria-labelledby   →  text from referenced element(s)
2. aria-label        →  author-provided string
3. Native sources    →  <label>, alt, <title>, value, text content
4. title attribute   →  last resort (often skipped by AT)
```

| Source | Example | Dùng cho |
|--------|---------|-------------------------|
| **`aria-labelledby`** | `<button aria-labelledby="btn-label">…</button>` | Chữ hiển thị ở chỗ khác |
| **`aria-label`** | `<button aria-label="Close">×</button>` | Control chỉ icon |
| **Native** | `<img alt="…">`, `<label>`, button text | Đường mặc định — ưu tiên |
| **`title`** | `<a title="Home">` | Chỉ tooltip; không tin cậy làm tên duy nhất |

```html
<!-- aria-labelledby wins over aria-label and inner text -->
<button aria-label="Dismiss" aria-labelledby="save-label">
  <span id="save-label">Save draft</span>
</button>
<!-- Accessible name: "Save draft" -->
```

> **Một tên mỗi control** — nguồn trùng hoặc mâu thuẫn làm rối người dùng; chọn một chiến lược chính và giữ nhất quán. Mô tả (`aria-describedby`) tách biệt và đọc *sau* tên.

## 2. Viết alt text tốt

Thuộc tính **`alt`** trên `<img>` cung cấp tên accessible khi ảnh mang thông tin. Alt text tốt mô tả **mục đích và nghĩa trong ngữ cảnh**, không phải chú thích kiểu máy ảnh.

| Context | Alt tệ | Alt tốt |
|---------|-------------------|---------------------|
| Product card | "image of shoes" | "Running shoes, blue, size 42" |
| Team page portrait | "photo" | "Jane Doe, Head of Engineering" |
| Chart in article | "chart" | "Q3 revenue up 18% year over year" |
| Logo in header linking home | "company logo" | "Acme Corp, home" |

Quy tắc ngón tay cái:

- **Bỏ** "image of", "picture of", "graphic of" — AT đã đọc "image".
- **Ngắn gọn** — một câu; chuyển dữ liệu dài sang text hiển thị hoặc mô tả dài.
- **Khớp ý định** — ảnh chức năng (trong link/button) mô tả **hành động**, không phải pixel.

```html
<!-- Informative: alt describes content -->
<img
  src="/team/jane.jpg"
  alt="Jane Doe, Head of Engineering, smiling at a laptop"
  width="200"
  height="200"
>

<!-- Functional: alt describes what happens when activated -->
<a href="/cart">
  <img src="/icons/cart.svg" alt="View shopping cart">
</a>
```

## 3. Ảnh trang trí vs ảnh mang thông tin

**Ảnh trang trí** tăng thẩm mỹ nhưng không mang thông tin — gradient hero, họa tiết phân cách, icon lặp cạnh chữ hiển thị. Đánh dấu để AT **bỏ qua**:

```html
<!-- Decorative: empty alt — not missing alt -->
<img src="/patterns/wave.svg" alt="" role="presentation">

<!-- Informative: meaningful alt required -->
<img src="/chart-q3.png" alt="Q3 revenue increased 18% compared to Q3 last year">
```

| Type | `alt` value | Hành vi AT |
|------|-------------|----------------------------|
| **Informative** | Descriptive string | Đọc chuỗi |
| **Decorative** | `""` (empty) | Bỏ qua ảnh |
| **Missing `alt`** | (attribute absent) | Có thể đọc tên file — tránh |

Nếu ảnh cạnh caption hiển thị mô tả đủ, có thể dùng `alt=""` **chỉ khi** caption liên kết lập trình (vd `<figure>` + `<figcaption>`) và người dùng AT nhận cùng thông tin.

```html
<figure>
  <img src="/office.jpg" alt="">
  <figcaption>New headquarters in District 1, opened March 2026.</figcaption>
</figure>
```

## 4. Nút chỉ icon và icon inline

Button chỉ chứa SVG hoặc `<img>` **không có text** cho thuật toán tên — bạn phải cung cấp.

```tsx
<button type="button" aria-label="Close dialog" onClick={onClose}>
  <svg aria-hidden="true" viewBox="0 0 24 24" /* … */>
    <path d="M6 6l12 12M18 6L6 18" />
  </svg>
</button>
```

Pattern:

1. **`aria-label`** trên button (hoặc `aria-labelledby` trỏ text ẩn thị giác).
2. **`aria-hidden="true"`** trên icon trang trí bên trong — tránh đọc đúp.

Khi icon đi kèm **chữ hiển thị**, chữ là tên — ẩn icon khỏi AT:

```html
<button type="button">
  <svg aria-hidden="true" /* trash icon */></svg>
  Delete item
</button>
<!-- Name: "Delete item" — no aria-label needed -->
```

## 5. SVG inline

SVG inline là DOM — không dùng `alt`. Hai đường:

### SVG mang thông tin

```html
<svg role="img" aria-labelledby="chart-title" viewBox="0 0 400 200">
  <title id="chart-title">Monthly active users, Jan–Jun 2026</title>
  <!-- paths… -->
</svg>
```

- **`role="img"`** — báo AT xử lý đồ họa như ảnh.
- **`<title>`** trong SVG, tham chiếu bởi **`aria-labelledby`** — ưu tiên hơn `aria-label` cho SVG phức tạp.

### SVG trang trí

```html
<button type="button" aria-label="Settings">
  <svg aria-hidden="true" focusable="false" /* gear icon */></svg>
</button>
```

Dùng **`aria-hidden="true"`** và **`focusable="false"`** (cho IE/SVG tab cũ) trên SVG inline thuần trang trí.

## 6. Ảnh phức tạp — biểu đồ, đồ thị, sơ đồ

Biểu đồ không gói gọn trong một câu alt — dùng **tóm tắt ngắn** trong `alt` cộng **mô tả dài** gần đó hoặc qua `aria-describedby`.

```html
<img
  id="revenue-chart"
  src="/charts/revenue-q3.png"
  alt="Bar chart: Q3 revenue by region"
  aria-describedby="revenue-chart-desc"
>
<div id="revenue-chart-desc">
  <p>North America: $4.2M (+12%). Europe: $2.8M (+22%). APAC: $1.9M (+31%).</p>
  <table>
    <caption>Q3 revenue by region (USD millions)</caption>
    <!-- full data table for AT and sighted users -->
  </table>
</div>
```

Thực hành tốt: cung cấp **cùng dữ liệu dạng bảng** hoặc tóm tắt text — alt một mình không đủ cho dữ liệu dày. Với biểu đồ canvas/WebGL, phơi dữ liệu qua bảng ẩn hoặc `aria-label` trên container cộng toggle xem dữ liệu hiển thị.

## 7. Ảnh nền và nội dung CSS

**Ảnh nền CSS** (`background-image`, `url()` trong style) **không** nằm trong cây accessibility — screen reader không cảm nhận được. Nếu thông tin chỉ nằm trong ảnh nền, nó **không accessible**.

```css
/* ❌ Critical text baked into background — invisible to AT */
.hero {
  background-image: url('/promo-50-off.png');
}

/* ✅ Same message in HTML; background is decorative only */
.hero h2 { /* "50% off annual plans" — readable by everyone */ }
.hero { background-image: url('/promo-texture.png'); }
```

Đừng đặt chữ thiết yếu, icon có nghĩa, hay dữ liệu biểu đồ trong nền CSS hay pseudo-element mà không có bản HTML tương đương.

## 8. Ảnh chức năng trong link và button

Khi ảnh là **toàn bộ nội dung** của link hoặc button, `alt` mô tả **đích hoặc hành động**, không phải tác phẩm.

```html
<!-- Link: alt = where you go -->
<a href="/downloads/report.pdf">
  <img src="/icons/pdf.svg" alt="Download 2026 annual report (PDF, 2.4 MB)">
</a>

<!-- Button: alt = what happens (prefer visible text + aria-hidden icon instead) -->
<button type="submit">
  <img src="/icons/search.svg" alt="" aria-hidden="true">
  Search
</button>
```

| Pattern | Accessible name source |
|---------|------------------------|
| `<a><img alt="…"></a>` | `alt` ảnh |
| `<button><img alt="…"></button>` | `alt` ảnh (ưu tiên thêm chữ hiển thị) |
| `<button aria-label="…"><img alt=""></button>` | `aria-label` trên button |

Tránh "link" hay "button" thừa trong alt — AT đọc role.

> **WCAG 1.1.1 Non-text Content** — mọi nội dung không-text mang thông tin cần thay thế bằng text; nội dung thuần trang trí dùng `alt=""`.

---

## Tóm tắt

- Tên accessible theo **stack ưu tiên**: `aria-labelledby` → `aria-label` → nguồn gốc → `title`.
- Viết **alt text** theo mục đích trong ngữ cảnh — ngắn, không "image of", hướng hành động trong link/button.
- **Trang trí**: `alt=""`; **mang thông tin**: `alt` có nghĩa; không bỏ `alt` trên ảnh nội dung.
- **Nút chỉ icon** cần `aria-label`; đánh dấu icon `aria-hidden` khi chữ đã đặt tên control.
- **SVG**: `role="img"` + `<title>`/`aria-labelledby`, hoặc `aria-hidden` nếu trang trí; biểu đồ cần alt ngắn + mô tả dài hoặc bảng dữ liệu.
- **Nền CSS** không truyền gì cho AT — đặt thông tin thiết yếu trong HTML.

**Phần tiếp theo:** Accessibility màu sắc và thị giác — tương phản, zoom, giảm chuyển động, và chỉ báo focus ngoài `:focus-visible`.
