## 1. Cài đặt

```bash
npm install react-hook-form zod @hookform/resolvers
npx shadcn@latest add form input button
```

`@hookform/resolvers` là chất keo giữa zod và react-hook-form. shadcn `form` thêm `Form`, `FormField`, `FormItem`, `FormLabel`, `FormControl`, `FormMessage`.

---

## 2. Schema là nguồn sự thật duy nhất

Định nghĩa hình dạng **một lần** bằng zod. Nó làm hai việc: **validate** lúc runtime *và* **type** form qua suy luận:

```ts
import { z } from 'zod';

export const signupSchema = z.object({
  username: z.string().min(3, 'At least 3 characters').max(20).regex(/^\w+$/, 'Letters, numbers, _ only'),
  email: z.string().email('Enter a valid email'),
  age: z.coerce.number().int().min(13, 'Must be at least 13'),
  password: z.string().min(8, 'At least 8 characters').regex(/\d/, 'Include a number'),
});

// the form's TS type — derived, never hand-written
export type SignupValues = z.infer<typeof signupSchema>;
```

Không `interface` trùng, không lệch giữa validate và type. Đổi schema và TypeScript lập tức báo mọi nơi bị ảnh hưởng. Để ý `z.coerce.number()` — input form là chuỗi, `coerce` chuyển đổi trước khi validate.

## 3. Nối với react-hook-form

```tsx
import { useForm } from 'react-hook-form';
import { zodResolver } from '@hookform/resolvers/zod';
import { signupSchema, type SignupValues } from './schema';

const form = useForm<SignupValues>({
  resolver: zodResolver(signupSchema),
  defaultValues: { username: '', email: '', age: 13, password: '' },
  mode: 'onBlur', // validate when a field loses focus
});
```

Sao dùng `react-hook-form` thay vì `useState` mỗi field? **Hiệu năng và trải nghiệm**. Nó theo dõi input qua ref (uncontrolled), nên gõ một field không re-render cả form. Bạn có `formState.errors`, `isValid`, `isDirty`, `isSubmitting` sẵn.

---

## 4. Render với component `Form` của shadcn

Các phần `Form` của shadcn nối **a11y tự động** — gắn label↔input, `aria-invalid`, `aria-describedby` tới lỗi, quản lý focus:

```tsx
import { Form, FormField, FormItem, FormLabel, FormControl, FormMessage, FormDescription } from '@/components/ui/form';
import { Input } from '@/components/ui/input';
import { Button } from '@/components/ui/button';

export function SignupForm() {
  const form = useForm<SignupValues>({ resolver: zodResolver(signupSchema), defaultValues: { /* … */ } });

  function onSubmit(values: SignupValues) {
    // values is fully typed AND already validated
    console.log(values);
  }

  return (
    <Form {...form}>
      <form onSubmit={form.handleSubmit(onSubmit)} className="space-y-4">
        <FormField
          control={form.control}
          name="username"
          render={({ field }) => (
            <FormItem>
              <FormLabel>Username</FormLabel>
              <FormControl>
                <Input placeholder="janedoe" {...field} />
              </FormControl>
              <FormDescription>3–20 chars, letters/numbers/underscore.</FormDescription>
              <FormMessage /> {/* renders the zod error for this field */}
            </FormItem>
          )}
        />

        <FormField
          control={form.control}
          name="email"
          render={({ field }) => (
            <FormItem>
              <FormLabel>Email</FormLabel>
              <FormControl><Input type="email" {...field} /></FormControl>
              <FormMessage />
            </FormItem>
          )}
        />

        <Button type="submit" disabled={form.formState.isSubmitting}>
          Create account
        </Button>
      </form>
    </Form>
  );
}
```

`FormMessage` hiện lỗi zod tự động — bạn không bao giờ viết `{errors.email && <p>…</p>}`. `{...field}` spread `value`, `onChange`, `onBlur`, `ref` từ react-hook-form vào input.

## 5. Ngoài input chữ

Cùng mẫu `FormField` bọc mọi control — `Select`, `Checkbox`, `Switch`, `RadioGroup` của shadcn. Với control không phải chữ, bạn bind tường minh:

```tsx
<FormField control={form.control} name="plan" render={({ field }) => (
  <FormItem>
    <FormLabel>Plan</FormLabel>
    <Select onValueChange={field.onChange} defaultValue={field.value}>
      <FormControl><SelectTrigger><SelectValue /></SelectTrigger></FormControl>
      <SelectContent>
        <SelectItem value="free">Free</SelectItem>
        <SelectItem value="pro">Pro</SelectItem>
      </SelectContent>
    </Select>
    <FormMessage />
  </FormItem>
)} />
```

## 6. Validate phía server & lỗi

Tái dùng **cùng schema** trên server (chỉ là zod) và ánh xạ lỗi server về form:

```ts
// server: parse the same schema
const parsed = signupSchema.safeParse(body);
if (!parsed.success) return { errors: parsed.error.flatten().fieldErrors };
```

```tsx
// client: surface a field error returned by the server
form.setError('email', { message: 'This email is already taken' });
```

Một schema, validate cả hai đầu — không nhân đôi logic.

## 7. Bài tập

**1.** Vì sao một schema zod tốt hơn `interface` TS riêng + validate thủ công?

<details>
<summary>Lời giải</summary>

Schema là nguồn sự thật duy nhất: `z.infer` suy ra type nên không lệch khỏi luật validate, và cùng schema chạy ở client lẫn server.
</details>

**2.** Vì sao dùng `z.coerce.number()` cho input tuổi thay vì `z.number()`?

<details>
<summary>Lời giải</summary>

Input HTML cho ra chuỗi; `coerce` chuyển chuỗi thành số trước khi validate, nên `"18"` thành `18`.
</details>

**3.** `<FormMessage />` giúp bạn khỏi viết gì?

<details>
<summary>Lời giải</summary>

Render lỗi và nối dây thủ công — nó hiện lỗi của field và nối ARIA tự động.
</details>

Nâng cao:trong lab, sửa mọi field thành hợp lệ và xem `isValid` thành `true` cùng object errors rỗng đi.

## Điểm chính

- **Một schema zod** type *và* validate form — `z.infer` xóa lệch type.
- `react-hook-form` cho state hiệu năng cao (uncontrolled) và `formState` phong phú; `zodResolver` nối chúng.
- Các phần `Form` của shadcn nối **a11y và hiển thị lỗi** miễn phí.
- Tái dùng schema trên server để validate đầu-cuối không nhân đôi.
