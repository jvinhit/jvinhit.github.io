## 1. Lerp — viên gạch của mọi animation

**Linear interpolation (lerp)** tính một giá trị nằm giữa `a` và `b` theo tỉ lệ `t` (từ 0 tới 1). Nó là nền của mọi chuyển động, đổi màu, di chuyển.

```ts
function lerp(a: number, b: number, t: number): number {
  return a + (b - a) * t; // t=0 → a, t=1 → b, t=0.5 → midpoint
}

// Inverse: where does value sit between a and b? (normalize to 0..1)
function inverseLerp(a: number, b: number, value: number): number {
  return (value - a) / (b - a);
}

// Map a value from one range to another (very common for sliders, scroll progress)
function mapRange(value: number, inMin: number, inMax: number, outMin: number, outMax: number): number {
  return lerp(outMin, outMax, inverseLerp(inMin, inMax, value));
}
```

```ts
// Example: scroll from 0..500px → header opacity from 1..0
const opacity = mapRange(scrollY, 0, 500, 1, 0);
```

Một kỹ thuật mượt rẻ tiền là **lerp dần về đích mỗi frame** (smoothing), tạo hiệu ứng "đuổi theo" tự nhiên cho con trỏ tùy biến hay parallax:

```ts
let current = 0;
function frame(target: number) {
  current = lerp(current, target, 0.1); // each frame moves 10% of remaining distance → natural ease-out
  el.style.transform = `translateX(${current}px)`;
  requestAnimationFrame(() => frame(target));
}
```

## 2. Easing: làm chuyển động tự nhiên

Chuyển động tuyến tính trông "máy móc". **Easing** bẻ cong quan hệ giữa thời gian và tiến độ để có gia tốc/giảm tốc tự nhiên. Easing chỉ là hàm nhận `t` (0..1) trả về `t'` (0..1) đã bẻ cong:

```ts
const easing = {
  linear: (t: number) => t,
  easeInQuad: (t: number) => t * t, // slow then fast
  easeOutQuad: (t: number) => t * (2 - t), // fast then slow (feels good for UI entry)
  easeInOutCubic: (t: number) => (t < 0.5 ? 4 * t ** 3 : 1 - (-2 * t + 2) ** 3 / 2),
};
```

Ghép lerp + easing thành một tween tự viết, chạy theo `requestAnimationFrame` (Phần 8):

```ts
function animate(opts: {
  from: number;
  to: number;
  duration: number;
  ease?: (t: number) => number;
  onUpdate: (value: number) => void;
  onDone?: () => void;
}): () => void {
  const { from, to, duration, ease = easing.easeOutQuad, onUpdate, onDone } = opts;
  const start = performance.now();
  let rafId = 0;

  const tick = (now: number) => {
    const t = Math.min(1, (now - start) / duration); // time progress 0..1
    onUpdate(lerp(from, to, ease(t))); // lerp along eased progress
    if (t < 1) rafId = requestAnimationFrame(tick);
    else onDone?.();
  };
  rafId = requestAnimationFrame(tick);
  return () => cancelAnimationFrame(rafId); // return cancel fn for cleanup on unmount
}
```

> CSS transition/animation chạy trên compositor và thường mượt hơn JS. Chỉ tween bằng JS khi cần điều khiển từng frame (theo scroll, theo con trỏ, vật lý). Khi tween JS, chỉ chạm `transform`/`opacity` để tránh layout/paint (Phần 1).

## 3. Hit-testing: điểm có nằm trong hình không

Drag-drop, tooltip, menu ngữ cảnh đều cần biết "con trỏ có nằm trong vùng này không".

```ts
interface Rect {
  x: number;
  y: number;
  width: number;
  height: number;
}

function pointInRect(px: number, py: number, r: Rect): boolean {
  return px >= r.x && px <= r.x + r.width && py >= r.y && py <= r.y + r.height;
}

// Do two rectangles overlap? (for collision / drop zone)
function rectsOverlap(a: Rect, b: Rect): boolean {
  return a.x < b.x + b.width && a.x + a.width > b.x && a.y < b.y + b.height && a.y + a.height > b.y;
}

// Point inside a circle (radius) — for round buttons, touch targets
function pointInCircle(px: number, py: number, cx: number, cy: number, r: number): boolean {
  const dx = px - cx;
  const dy = py - cy;
  return dx * dx + dy * dy <= r * r; // compare squared distance to skip sqrt (faster)
}
```

Mẹo nhỏ nhưng quan trọng: so **bình phương khoảng cách** thay vì gọi `Math.sqrt` — kết quả so sánh như nhau mà tiết kiệm phép căn, đáng kể khi kiểm tra hàng nghìn điểm mỗi frame.

## 4. Drag với snap-to-grid

Kéo thả là `pointermove` + cập nhật `transform`. Thêm **snap-to-grid** chỉ là làm tròn tọa độ về bội số gần nhất:

```ts
function snap(value: number, gridSize: number): number {
  return Math.round(value / gridSize) * gridSize;
}

function makeDraggable(el: HTMLElement, gridSize = 20): void {
  let startX = 0, startY = 0, originX = 0, originY = 0;

  el.addEventListener('pointerdown', (e) => {
    startX = e.clientX;
    startY = e.clientY;
    originX = el.offsetLeft;
    originY = el.offsetTop;
    el.setPointerCapture(e.pointerId); // receive all pointer events until release, even outside el
    el.addEventListener('pointermove', onMove);
  });

  const onMove = (e: PointerEvent) => {
    // snap to grid so elements align
    const x = snap(originX + (e.clientX - startX), gridSize);
    const y = snap(originY + (e.clientY - startY), gridSize);
    el.style.transform = `translate(${x - originX}px, ${y - originY}px)`;
  };

  el.addEventListener('pointerup', (e) => {
    el.releasePointerCapture(e.pointerId);
    el.removeEventListener('pointermove', onMove);
  });
}
```

`setPointerCapture` là chi tiết "pro": nó đảm bảo bạn tiếp tục nhận `pointermove` cả khi con trỏ ra ngoài phần tử — không có nó, kéo nhanh sẽ "rớt" phần tử.

## 5. FLIP: animation layout 60fps

Animate thay đổi **layout** (vị trí, kích thước khi sắp xếp lại danh sách) trực tiếp sẽ chậm vì gây reflow mỗi frame. Kỹ thuật **FLIP** (First, Last, Invert, Play) né điều đó: đo trước/sau, dùng `transform` để "giả vờ" còn ở chỗ cũ, rồi animate transform về 0 (transform không gây reflow).

```ts
function flip(el: HTMLElement, mutate: () => void): void {
  const first = el.getBoundingClientRect(); // First: position before
  mutate(); // change DOM (reorder, toggle class...) → browser jumps to new position
  const last = el.getBoundingClientRect(); // Last: position after

  const dx = first.left - last.left; // Invert: offset to pull back to old spot
  const dy = first.top - last.top;

  el.animate(
    [
      { transform: `translate(${dx}px, ${dy}px)` }, // start at old position (transform only)
      { transform: 'translate(0, 0)' }, // Play: slide to new position
    ],
    { duration: 250, easing: 'ease-out' },
  );
}
```

FLIP chỉ dùng `transform` (chạy trên compositor) nên mượt 60fps dù layout đổi nhiều. Đây là kỹ thuật đứng sau các animation "magic move" / shared layout của Framer Motion và `react-flip-toolkit`.

## 6. Tôn trọng `prefers-reduced-motion`

Một phần "đúng chuẩn senior": luôn kiểm tra người dùng có yêu cầu giảm chuyển động không (accessibility), và rút gọn hoặc tắt animation:

```ts
const reduceMotion = matchMedia('(prefers-reduced-motion: reduce)').matches;
const duration = reduceMotion ? 0 : 250; // disable animation if user requested
```

## Tóm tắt

- **lerp / inverseLerp / mapRange** là viên gạch của mọi animation và ánh xạ giá trị (scroll → opacity, slider...).
- **Easing** bẻ cong tiến độ cho chuyển động tự nhiên; ghép với `requestAnimationFrame` để tween thủ công, chỉ chạm `transform`/`opacity`.
- **Hit-testing** (point-in-rect/circle, overlap) cho drag-drop; so **bình phương khoảng cách** thay vì căn.
- **Drag** dùng `setPointerCapture` + `snap` để kéo mượt và thẳng hàng.
- **FLIP** animate layout 60fps chỉ bằng transform; luôn tôn trọng `prefers-reduced-motion`.
