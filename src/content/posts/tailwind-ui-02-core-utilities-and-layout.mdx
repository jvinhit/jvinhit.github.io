Phần 1 đã cho bạn mô hình tư duy và một setup v4 chạy được. Giờ ta xây vốn từ. Đây là **80% Tailwind bạn dùng 80% thời gian** — spacing, sizing, type, màu, và hai cỗ máy layout. Nắm chắc phần này là bạn dựng được gần như mọi UI tĩnh.

---

## 1. Thang spacing — nhịp tim

Gần như mọi utility spacing dùng chung **một thang số** với `n` nghĩa là `n × 0.25rem` (4px ở cỡ gốc mặc định).

| Class | Value | Class | Value |
|---|---|---|---|
| `p-1` | `0.25rem` | `p-6` | `1.5rem` |
| `p-2` | `0.5rem` | `p-8` | `2rem` |
| `p-4` | `1rem` | `p-12` | `3rem` |

Các tiền tố bạn dùng liên tục:

- Padding: `p`, `px`/`py` (trục), `pt`/`pr`/`pb`/`pl` (cạnh)
- Margin: `m`, `mx`/`my`, `mt`…, và `mx-auto` để căn giữa
- Gap (flex/grid): `gap`, `gap-x`, `gap-y`

```html
<div class="px-4 py-2">horizontal 1rem, vertical 0.5rem</div>
<div class="mt-6 mb-2">top 1.5rem, bottom 0.5rem</div>
```

> **`space-x/space-y` vs `gap`**: `space-y-4` thêm margin *giữa* các con (không tính rìa); `gap-4` cần cha là flex/grid nhưng gọn hơn. Ưu tiên `gap` khi cha đã là flex hoặc grid.

## 2. Kích thước — width, height, min/max

Sizing trộn thang spacing với phân số và từ khóa:

```html
<div class="w-64">width: 16rem (64 × 0.25)</div>
<div class="w-1/2">width: 50%</div>
<div class="w-full h-screen">100% wide, 100vh tall</div>
<div class="max-w-sm">max-width: 24rem — great for cards & prose</div>
<div class="size-10">width AND height: 2.5rem (v4 shorthand)</div>
```

Thang `max-w-*` (`max-w-sm` … `max-w-7xl`, `max-w-prose`) là cách giữ nội dung dễ đọc trên màn hình rộng.

## 3. Typography & màu

```html
<p class="text-sm">0.875rem</p>
<p class="text-lg font-semibold tracking-tight leading-relaxed">
  size, weight, letter-spacing, line-height
</p>
<p class="text-slate-600">color from the palette</p>
<p class="text-indigo-500/70">indigo at 70% opacity (the /opacity modifier)</p>
```

Các nhóm chính: `text-{xs..9xl}` kích thước, độ đậm, giãn chữ, giãn dòng, màu. Bộ chỉnh độ mờ `/NN` chạy với gần như mọi utility màu.

## 4. Flexbox — kiểu Tailwind

Mọi khái niệm Flexbox là một utility:

| CSS | Tailwind |
|---|---|
| `display: flex` | `flex` |
| `flex-direction: column` | `flex-col` |
| `justify-content: space-between` | `justify-between` |
| `align-items: center` | `items-center` |
| `gap: 1rem` | `gap-4` |
| `flex: 1 1 0%` | `flex-1` |

Layout phổ biến nhất trong mọi UI — một hàng căn giữa, đẩy các item ra hai bên:

```html
<header class="flex items-center justify-between gap-4">
  <span class="font-semibold">Logo</span>
  <nav class="flex gap-4">…</nav>
</header>
```

## 5. Grid — cho layout hai chiều

```html
<div class="grid grid-cols-3 gap-4">
  <div>…</div><div>…</div><div>…</div>
</div>
```

`grid-cols-3` → ba cột bằng nhau. Cho item chiếm nhiều cột bằng `col-span-2`, đặt hàng với `grid-rows-*`, định vị với `col-start-*`.

## 6. Responsive — mobile-first

Đây là khái niệm làm người mới vấp, nên hãy thấm nó:

> **Utility không tiền tố áp ở mọi cỡ. Tiền tố như `md:` nghĩa là "từ breakpoint này trở lên."**

Các breakpoint mặc định: `sm` 640....

```html
<!-- 1 column on phones, 2 from md, 3 from lg -->
<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4">…</div>
```

Bạn thiết kế **màn hình nhỏ nhất trước** (class không tiền tố), rồi thêm override *chỉ áp khi to lên*. Đọc từ trên xuống như một câu chuyện: "xếp chồng trên mobile, cạnh nhau trên tablet, ba cột trên desktop".

Lỗi thường gặp: viết `md:flex` rồi mong nó *cũng* ảnh hưởng mobile. Không đâu — `md:` bắt đầu từ 768px. Muốn "flex mọi nơi, cột trên mobile, hàng trên desktop" bạn viết `flex flex-col md:flex-row`.

## 7. Bài tập

**1.** Dựng navbar: full width, item căn giữa dọc, logo bên trái và nhóm link bên phải, gap `1rem`.

<details>
<summary>Lời giải</summary>

```html
<header class="flex items-center justify-between gap-4 px-6 py-4">
  <span class="font-semibold">Logo</span>
  <nav class="flex gap-4"><a>Home</a><a>Docs</a><a>About</a></nav>
</header>
```
</details>

**2.** Lưới card responsive: 1 cột mobile, 2 từ `sm`, 3 từ `lg`, gap `1.5rem`.

<details>
<summary>Lời giải</summary>

```html
<div class="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-6">…</div>
```
</details>

**3.** Căn giữa một box cả ngang và dọc trong một section cao full màn hình.

<details>
<summary>Lời giải</summary>

```html
<section class="flex items-center justify-center h-screen">
  <div class="max-w-sm">Centered</div>
</section>
```
</details>

Nâng cao:trong builder ở trên, tạo layout **cột xếp chồng khi hẹp** và **hàng khi rộng** bằng override `md:`, rồi đọc khối `@media` sinh ra.

---

## Điểm chính

- Một **thang spacing** chi phối padding, margin, gap — nên UI Tailwind có nhịp nhất quán.
- **Flexbox** cho hàng/cột một chiều; **Grid** cho layout hai chiều — mỗi thuộc tính CSS có utility tương ứng.
- Responsive là **mobile-first**: không tiền tố = mọi cỡ, `md:`/`lg:` = breakpoint đó *trở lên*.
