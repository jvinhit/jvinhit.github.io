## 1. Tỷ lệ tương phản — con số quan trọng

**Tỷ lệ tương phản** đo chênh lệch độ sáng giữa chữ/nét và nền, biểu diễn từ 1:1 (giống hệt) tới 21:1 (đen trên trắng). WCAG định nghĩa ngưỡng ở mức **AA** (mục tiêu thực tế) và **AAA** (nghiêm hơn):

| Content type | WCAG AA | WCAG AAA |
|--------------|---------|----------|
| **Chữ thường** | **4.5:1** | **7:1** |
| **Chữ lớn** | **3:1** | **4.5:1** |
| **Component UI & đồ họa** | so với màu liền kề | — |
| **Chỉ báo focus** | **3:1** against adjacent colors | — |

> **Mẹo chữ lớn:** 24px thường hoặc 18.66px bold (19px nếu làm tròn) đủ ngưỡng 3:1 — nhưng đừng dùng làm cớ thu nhỏ body copy.

### Cách đo

Bạn không cần tự tính luminance:

- **Chrome DevTools** — inspect phần tử → pane **Accessibility** hiện tỷ lệ và pass/fail AA/AAA.
- **Firefox DevTools** — inspector **Accessibility** có mục color-contrast.
- **Công cụ riêng** — WebAIM, CCA (app desktop, có eyedropper).
- **Công cụ design** — plugin Figma bắt lỗi trước khi code.

```css
/* Design tokens — pick pairs that pass 4.5:1 on your bg */
:root {
  --color-bg: #0a0a0a;
  --color-text: #e8e8e8;       /* ~15:1 on #0a0a0a — passes AAA */
  --color-text-muted: #a3a3a3; /* ~7.5:1 — passes AA for normal text */
  --color-accent: #c8ff00;     /* verify against bg — lime on dark often passes */
  --color-error: #ff6b6b;      /* check: red-on-dark may fail — adjust lightness */
}
```

Luôn kiểm tra **cả sáng-trên-tối và tối-trên-sáng** nếu hỗ trợ đổi theme — cặp pass ở dark mode có thể fail khi đảo.

## 2. Không chỉ dựa vào màu (WCAG 1.4.1)

Màu là kênh thị giác mạnh, nhưng khoảng **1/12 nam** và **1/200 nữ** có rối loạn thị giác màu (CVD) — deuteranopia, protanopia, tritanopia, v.v.. Chói nắng, màn hình rẻ, máy chiếu mờ cũng gây vấn đề tương tự cho mọi người.

**WCAG 1.4.1** yêu cầu thông tin truyền qua màu còn có qua kênh thị giác khác — chữ, icon, pattern, gạch chân, hoặc hình dạng.

| Pattern | ❌ Color only | ✅ Color + secondary cue |
|---------|--------------|-------------------------|
| Lỗi form | Red border only | Red border + error icon + text message linked with `aria-describedby` |
| Trường bắt buộc | Red asterisk only | Asterisk + "(required)" text or `aria-required="true"` |
| Link trong đoạn | Blue text, no underline | Underline (or bold + underline) — not color alone |
| Phân đoạn biểu đồ | Green vs red slices | Distinct patterns/hatch + labels + legend |
| Badge trạng thái | Green "Active" / gray "Inactive" | Icon + text label; don't rely on hue alone |

```html
<!-- ❌ Error indicated only by red border -->
<input type="email" class="border-red-500" />

<!-- ✅ Error: border + icon + explicit message -->
<label for="email">Email</label>
<input
  id="email"
  type="email"
  aria-invalid="true"
  aria-describedby="email-error"
  class="border-error"
/>
<p id="email-error" class="text-error flex items-center gap-1">
  <svg aria-hidden="true" class="size-4"><!-- error icon --></svg>
  Enter a valid email address
</p>
```

```tsx
// React: status with icon + text, not hue alone
function StatusBadge({ status }: { status: 'active' | 'inactive' | 'pending' }) {
  const config = {
    active: { icon: '●', label: 'Active', className: 'text-success' },
    inactive: { icon: '○', label: 'Inactive', className: 'text-muted' },
    pending: { icon: '◐', label: 'Pending', className: 'text-warning' },
  } as const;
  const { icon, label, className } = config[status];

  return (
    <span className={className}>
      <span aria-hidden="true">{icon}</span>
      {label}
    </span>
  );
}
```

## 3. Zoom và reflow (1.4.4 & 1.4.10)

Người kém thị lực thường duyệt ở **zoom 200%** trở lên — macOS và Windows đều có phóng đại cấp hệ thống. **WCAG 1.4.4** yêu cầu chữ phóng tới 200% không mất nội dung hay chức năng (không scroll ngang cho nội dung dọc ở chiều rộng mặc định).

**WCAG 1.4.10 Reflow** đi xa hơn: ở **320 CSS pixel** rộng (tương đương zoom 400% trên viewport 1280px), nội dung phải reflow không **scroll hai chiều** — không phải kéo trái-phải *và* lên-xuống để đọc một cột chữ.

### Thực hành pass

- Dùng **đơn vị tương đối** cho chữ: `rem`, `em`, `%` — không cố định `px` cho body.
- Tránh **chiều cao cố định** trên container chữ (`height: 48px` trên wrapper đoạn sẽ cắt chữ khi zoom).
- Ưu tiên **`min-height`** hơn `height` cho card và button.
- Dùng **flexbox/grid** với `flex-wrap` và cột linh hoạt — không absolute positioning cho khung layout.
- Không tắt zoom: `<meta ... maximum-scale=1>` là fail a11y.

```css
/* ✅ Scales with user font-size preference */
html {
  font-size: 100%; /* respects browser default, usually 16px */
}

body {
  font-size: 1rem;
  line-height: 1.6;
}

.card {
  min-height: 3rem;   /* grows with content */
  padding: 1rem 1.25rem;
  max-width: 100%;
}

/* ❌ Avoid */
.sidebar {
  height: 600px;      /* clips when text scales */
  overflow: hidden;
}
```

### Test nhanh

1. Zoom 200% — còn dùng được mọi control?
2. DevTools → 320px — body text có scroll ngang?
3. Tăng **cỡ chữ mặc định** hệ thống — layout `rem` có thích ứng?

## 4. Tôn trọng `prefers-reduced-motion`

Rối loạn tiền đình, migraine, ADHD và sở thích cá nhân khiến chuyển động lớn gây hại hoặc gây xao nhãng. **WCAG 2.3.3** yêu cầu chuyển động kích hoạt bởi tương tác có thể tắt trừ khi thiết yếu.

Media query **`prefers-reduced-motion`** phản ánh cài đặt OS ("Reduce motion" trên macOS/iOS, tắt "Show animations" trên Windows):

```css
/* Default: full animation */
.modal-overlay {
  animation: fade-in 200ms ease-out;
}

.slide-panel {
  transition: transform 300ms cubic-bezier(0.4, 0, 0.2, 1);
}

@keyframes fade-in {
  from { opacity: 0; }
  to { opacity: 1; }
}

/* Respect user preference */
@media (prefers-reduced-motion: reduce) {
  *,
  *::before,
  *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }

  /* Better: replace with opacity-only or instant show */
  .modal-overlay {
    animation: none;
    opacity: 1;
  }

  .slide-panel {
    transition: none;
    transform: none;
  }
}
```

**Đừng** dùng reset `*` blanket trên production mà không test — có thể hỏng spinner báo tiến trình. Ưu tiên rule có mục tiêu: tắt parallax, slide `translate` lớn, carousel tự chạy; giữ fade opacity nhẹ nếu cần.

```tsx
// React: hook for JS-driven animation
function usePrefersReducedMotion(): boolean {
  const [reduced, setReduced] = useState(false);

  useEffect(() => {
    const mq = window.matchMedia('(prefers-reduced-motion: reduce)');
    setReduced(mq.matches);
    const handler = (e: MediaQueryListEvent) => setReduced(e.matches);
    mq.addEventListener('change', handler);
    return () => mq.removeEventListener('change', handler);
  }, []);

  return reduced;
}

// Skip framer-motion layout animations when reduced
const reducedMotion = usePrefersReducedMotion();
<motion.div animate={reducedMotion ? false : { x: 0, opacity: 1 }} />
```

## 5. `prefers-contrast`, forced colors và dark mode

### Tùy chọn tương phản cao

**`prefers-contrast: more`** (hỗ trợ đang mở rộng) báo người dùng muốn viền rõ và tương phản cao hơn:

```css
@media (prefers-contrast: more) {
  :root {
    --color-border: #ffffff;
    --color-text-muted: #d4d4d4; /* bump muted text — don't drop below 4.5:1 */
  }

  button,
  input,
  select {
    border-width: 2px;
  }
}
```

### Forced colors / High Contrast Windows

Ở **forced-colors mode** (theme High Contrast Windows), OS ghi đè palette bằng màu hệ thống. Test với `@media (forced-colors: active)`:

```css
@media (forced-colors: active) {
  /* Don't remove borders — HC users rely on them */
  button {
    border: 1px solid ButtonText;
  }

  /* Ensure focus remains visible */
  :focus-visible {
    outline: 2px solid Highlight;
    outline-offset: 2px;
  }

  /* Icons that convey meaning need visible strokes */
  .status-icon {
    forced-color-adjust: none; /* use only when icon semantics require your colors */
  }
}
```

Tránh **`background-image`** là kênh duy nhất mang thông tin — có thể biến mất ở forced-colors.

### Dark mode và tương phản

Dark mode không tự accessible — `#777` trên `#222` thường fail 4.5:1. Dựng **cặp token riêng** mỗi theme và verify độc lập:

```css
:root {
  color-scheme: dark;
  --bg: #0a0a0a;
  --text: #e8e8e8;
  --text-muted: #a3a3a3;
  --border: #2a2a2a;
  --focus-ring: #c8ff00;
}

@media (prefers-color-scheme: light) {
  :root {
    color-scheme: light;
    --bg: #fafafa;
    --text: #171717;
    --text-muted: #525252;
    --border: #d4d4d4;
    --focus-ring: #65a30d; /* dark green — verify 3:1 on light bg */
  }
}
```

`color-scheme: dark` gợi ý control form và scrollbar gốc khớp theme — thắng UX nhỏ nhưng thật.

## 6. Chỉ báo focus pass (WCAG 2.4.11 & 1.4.11)

Phần 4 đã nói `:focus-visible` tốt hơn xóa hết outline. Phần 8 thêm **yêu cầu tương phản**: chỉ báo focus phải có tối thiểu **3:1** so với màu liền kề và dày tối thiểu **2 CSS pixel** (WCAG 2.2 **2.4.11 Focus Appearance**).

```css
/* ❌ Never */
:focus {
  outline: none;
}

/* ✅ Token-based focus ring */
:root {
  --focus-ring-color: #c8ff00;
  --focus-ring-width: 2px;
  --focus-ring-offset: 2px;
}

:focus-visible {
  outline: var(--focus-ring-width) solid var(--focus-ring-color);
  outline-offset: var(--focus-ring-offset);
}

/* Component on accent background — ring may fail 3:1; use offset + contrasting ring */
.btn-primary:focus-visible {
  outline-color: #ffffff;
  box-shadow: 0 0 0 2px var(--bg), 0 0 0 4px var(--focus-ring-color);
}
```

Thiết kế trạng thái focus **trong Figma cùng default và hover** — không phải hậu tố trong CSS. Vòng lime trên nút lime fail; double-ring trắng hoặc outline tối pass.

## 7. Tổng hợp — checklist a11y thị giác

Chạy trước khi ship bất kỳ mặt UI nào:

1. **Tương phản** — body ≥ 4.5:1, chữ lớn ≥ 3:1, viền UI ≥ 3:1.
2. **Màu + tín hiệu** — lỗi, link, trạng thái, biểu đồ có chữ/icon/pattern ngoài sắc độ.
3. **Zoom 200%** — không cắt chữ, không scroll ngang đoạn văn.
4. **Reflow 320px** — đọc một cột không scroll 2D.
5. **Giảm chuyển động** — parallax và transition lớn tắt dưới `prefers-reduced-motion`.
6. **Focus hiển thị** — mọi phần tử tương tác có vòng ≥ 2px, ≥ 3:1 trên `:focus-visible`.
7. **Forced colors** — viền và focus sống sót Windows High Contrast.

## Tóm tắt

- **Tỷ lệ tương phản** AA: chữ thường **4.5:1**, chữ lớn **3:1**, component UI và focus **3:1** — đo bằng DevTools hoặc công cụ chuyên dụng.
- **Không chỉ dựa màu** (1.4.1) — kết hợp sắc độ với icon, chữ, pattern, gạch chân cho lỗi, link, trạng thái, biểu đồ.
- Hỗ trợ **zoom 200%** và **reflow 320px** với `rem`, layout linh hoạt, không cắt chữ bằng chiều cao cố định.
- Tôn trọng **`prefers-reduced-motion`**, test **`forced-colors`**, verify **cặp token dark/light** độc lập.
- **Vòng focus** phải thấy, ≥ 2px, ≥ 3:1 — dùng `:focus-visible` và token, không `outline: none`.

**Phần tiếp theo:** Dựng component accessible — pattern disclosure, tabs, dialog và combobox từ WAI-ARIA Authoring Practices Guide.
