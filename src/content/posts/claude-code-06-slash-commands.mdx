Gõ `/` trong Claude Code và bạn thấy một danh sách rất dài. Docs liệt kê chúng theo thứ tự bảng chữ cái — tiện để tra, tệ để học.

Bài này gom lại **theo nhóm công việc**. Bạn không cần nhớ hết; chỉ cần biết nhóm nào tồn tại để lúc cần thì biết chỗ mà tìm.

## Ba loại thứ nằm sau dấu gạch chéo

Không phải mọi thứ gõ sau `/` đều cùng bản chất:

| Loại                 | Là gì                                                                                     | Ví dụ                               |
| -------------------- | ----------------------------------------------------------------------------------------- | ----------------------------------- |
| **Built-in command** | Lệnh dựng sẵn của CLI, chạy ngay trong client                                             | `/clear`, `/model`, `/context`      |
| **Bundled skill**    | Prompt đóng gói sẵn giao cho Claude. Claude tự gọi khi thấy liên quan, hoặc bạn gọi thẳng | `/code-review`, `/doctor`, `/debug` |
| **Bundled workflow** | Dynamic workflow toả việc ra nhiều subagent, chạy ở nền                                   | `/deep-research`, `/batch`          |

Khác biệt này quan trọng ở chỗ: built-in command là **code**, còn skill và workflow là **prompt/script** — nghĩa là bạn tự viết được cái của mình. Đó là nội dung phần 12 và phần 18.

> **Custom command đã được gộp vào skill.** Một file ở `.claude/commands/deploy.md` và một skill ở `.claude/skills/deploy/SKILL.md` đều tạo ra `/deploy` và hoạt động như nhau. File `.claude/commands/` cũ của bạn vẫn chạy bình thường.

## Lệnh nào chạy ngay, lệnh nào xếp hàng

Phần 5 đã nói về hàng đợi tin nhắn. Với command, quy tắc là: bạn xếp hàng được **phần lớn** command trong lúc Claude đang chạy, và Claude Code giữ chúng tới khi lượt kết thúc rồi chạy từng cái một.

Nhưng một số lệnh **chạy ngay lập tức**, không chờ:

- `/status` và `/tasks` — luôn chạy ngay
- `/permissions` — mở hộp thoại ngay, và thay đổi của bạn có hiệu lực từ tool call kế tiếp **trong cùng lượt**
- `/add-dir` — hỏi xác nhận ngay; xác nhận xong thì tool call kế tiếp trong cùng lượt đã dùng được thư mục đó
- `/resume`, `/theme`, `/security-review` — mở picker/hộp thoại ngay
- `/btw` — chạy độc lập, không cắt ngang lượt chính
- `/effort` và `/model` — có hiệu lực ngay, không chờ phản hồi hiện tại kết thúc

## Phiên và hội thoại

Nhóm dùng nhiều nhất. Phần 3 đã giải thích _vì sao_ nên dùng cái nào lúc nào; đây là _cái gì_.

| Lệnh                            | Tác dụng                                                                                                                    |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `/clear [name]`                 | Bắt đầu hội thoại mới với context rỗng. Truyền tên để gắn nhãn hội thoại cũ trong picker `/resume`. Alias: `/reset`, `/new` |
| `/compact [instructions]`       | Giải phóng context bằng cách tóm tắt hội thoại. Truyền chỉ dẫn để định hướng bản tóm tắt                                    |
| `/autocompact [auto\|<tokens>]` | Đặt ngưỡng context đầy trước khi vòng compact tự động chạy, ví dụ `500k`                                                    |
| `/context [all]`                | Trực quan hoá mức dùng context dạng lưới màu, kèm gợi ý tối ưu                                                              |
| `/resume`                       | Quay lại hội thoại trước. Liệt kê các lần clear và branch, kèm thời gian và tên bạn đặt                                     |
| `/branch [name]`                | Tạo một nhánh của hội thoại tại điểm này và **chuyển bạn sang nhánh đó**; bản gốc được giữ nguyên                           |
| `/fork [prompt]`                | Copy hội thoại sang một background session mới và **bạn ở lại đây làm tiếp**                                                |
| `/subtask <instruction>`        | Giao một việc cho subagent, kết quả báo ngược về hội thoại này                                                              |
| `/background [prompt]`          | Tách phiên hiện tại thành background agent và giải phóng terminal. Alias: `/bg`                                             |
| `/rewind`                       | Tua code và hội thoại về một checkpoint, hoặc tóm tắt một đoạn hội thoại để lấy chỗ                                         |
| `/recap`                        | Sinh tóm tắt một dòng của phiên hiện tại                                                                                    |
| `/btw [question]`               | Hỏi bên lề, không ghi vào lịch sử hội thoại                                                                                 |
| `/export [filename]`            | Xuất hội thoại ra văn bản thuần                                                                                             |
| `/copy [N]`                     | Copy phản hồi cuối vào clipboard. Truyền `N` để lấy phản hồi thứ N từ cuối lên                                              |
| `/diff`                         | Mở trình xem diff tương tác: thay đổi chưa commit và diff theo từng lượt                                                    |
| `/status`                       | Trạng thái phiên: model, effort level, thư mục làm việc, tóm tắt hoạt động gần đây                                          |
| `/usage`                        | Tổng hợp token và chi phí của phiên hiện tại và lịch sử gần đây. Alias: `/cost`                                             |
| `/insights`                     | Sinh report HTML phân tích các phiên gần đây trên máy này                                                                   |

Bốn lệnh dễ lẫn nhau — `/branch`, `/fork`, `/subtask`, `/background` — phân biệt bằng hai câu hỏi: _bản copy hay bản gốc chạy tiếp?_ và _kết quả có quay về hội thoại này không?_

| Lệnh          | Bạn ở lại đâu                       | Kết quả về đâu                |
| ------------- | ----------------------------------- | ----------------------------- |
| `/branch`     | Chuyển sang bản copy                | —                             |
| `/fork`       | Ở lại bản gốc                       | Không, bản copy chạy độc lập  |
| `/subtask`    | Ở lại                               | Có, subagent báo ngược về đây |
| `/background` | Rời terminal, phiên chạy tiếp ở nền | Xem qua `claude agents`       |

## Cấu hình

| Lệnh                      | Tác dụng                                                                                                                            |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `/config [key=value ...]` | Mở giao diện Settings, hoặc set thẳng một khoá: `/config theme=dark`. Chạy `/config --help` để liệt kê mọi khoá. Alias: `/settings` |
| `/model [model]`          | Đổi model và lưu làm mặc định cho phiên mới. Bấm `s` trên một dòng để chỉ đổi cho phiên hiện tại                                    |
| `/effort [level\|auto]`   | Đặt effort level: `low`, `medium`, `high`, `xhigh`, `max`, `ultracode`                                                              |
| `/fast [on\|off]`         | Bật/tắt fast mode                                                                                                                   |
| `/permissions`            | Quản lý allow, ask và deny rule. Alias: `/allowed-tools`                                                                            |
| `/hooks`                  | Xem cấu hình hook cho các sự kiện tool                                                                                              |
| `/memory`                 | Sửa `CLAUDE.md`, bật/tắt auto memory, xem các mục auto memory                                                                       |
| `/init`                   | Khởi tạo project với một `CLAUDE.md`                                                                                                |
| `/import [codex\|gemini]` | Mang cấu hình từ coding agent khác sang, gồm file chỉ dẫn, MCP server, command, subagent và skill                                   |
| `/add-dir <path>`         | Thêm một thư mục làm việc cho phiên hiện tại                                                                                        |
| `/cd <path>`              | Chuyển phiên sang thư mục làm việc khác, **giữ nguyên hội thoại và prompt cache**                                                   |
| `/theme [theme\|default]` | Đặt theme terminal: `light`, `dark`, `auto`                                                                                         |
| `/color [color\|default]` | Đặt màu thanh prompt cho phiên — khác `/theme`                                                                                      |
| `/keybindings`            | Mở file phím tắt của bạn                                                                                                            |
| `/vim`                    | Mở `vim` với phản hồi cuối của Claude để bạn sửa, rồi gửi lại kết quả                                                               |
| `/terminal-setup`         | Sinh cấu hình shell để thêm Claude Code vào `$PATH`                                                                                 |

`/cd` đáng chú ý hơn vẻ ngoài của nó: nó chuyển thư mục **mà không mất prompt cache**, trong khi mở một phiên mới ở thư mục khác thì mất sạch (xem phần 3 về cache scope).

## Review và chất lượng

| Lệnh                                                | Tác dụng                                                                                                                                                                                                 |
| --------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/code-review [level] [--fix] [--comment] [target]` | **Skill.** Review diff hiện tại, hoặc một PR/branch/path bạn truyền vào, tìm lỗi đúng-sai và chỗ dọn được. `--fix` để áp dụng, `--comment` để đăng thành inline comment trên GitHub PR. Alias: `/review` |
| `/security-review [--fix]`                          | Kiểm tra diff hiện tại tìm lỗ hổng bảo mật. Giống `/code-review` nhưng tập trung vào bảo mật                                                                                                             |
| `/simplify`                                         | **Skill.** Đề xuất cách đơn giản hoá code trong diff hiện tại **mà không đổi hành vi**                                                                                                                   |
| `/verify`                                           | **Skill.** Chạy test suite của project và báo cáo kết quả                                                                                                                                                |
| `/doctor`                                           | **Skill.** Kiểm tra thiết lập, chẩn đoán vấn đề và sửa được luôn. Alias: `/checkup`                                                                                                                      |
| `/debug [description]`                              | **Skill.** Bật debug logging cho phiên hiện tại và gỡ rối bằng cách đọc log                                                                                                                              |

`/doctor` làm nhiều hơn tên gọi: nó kiểm tra sức khoẻ cài đặt (bản cài trùng lặp, vấn đề `PATH`, file settings không parse được), tìm skill/MCP server/plugin **không dùng tới so với chi phí context** của chúng, chỉ ra hook chậm, gộp `CLAUDE.md` local trùng với bản đã commit, và cắt gọt `CLAUDE.md` đã commit. Nó **báo cáo trước và hỏi xác nhận** trước khi đổi bất cứ thứ gì.

## Nhiều agent và tự động hoá

| Lệnh                        | Tác dụng                                                                                                                                                                            |
| --------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/batch <instruction>`      | **Skill.** Điều phối thay đổi quy mô lớn song song: chia việc thành 5–30 đơn vị độc lập, mỗi đơn vị một background subagent trong git worktree riêng, mỗi cái tự chạy test và mở PR |
| `/deep-research <question>` | **Workflow.** Toả việc tìm kiếm web, tải và đối chiếu nguồn, tổng hợp thành báo cáo có trích dẫn                                                                                    |
| `/loop [interval] [prompt]` | **Skill.** Chạy lặp một prompt trong lúc phiên còn mở. Bỏ interval thì Claude tự căn nhịp. Alias: `/proactive`                                                                      |
| `/goal [condition\|clear]`  | Đặt mục tiêu: Claude làm tiếp qua nhiều lượt tới khi điều kiện đạt được hoặc bị đánh giá là bất khả thi                                                                             |
| `/tasks`                    | Liệt kê công việc nền trong phiên hiện tại, gồm cả subagent đã xong và kết quả của chúng                                                                                            |
| `/autofix-pr [prompt]`      | Sinh một phiên Claude Code on the web theo dõi PR của branch hiện tại và đẩy fix khi CI fail hoặc reviewer để lại comment                                                           |

## Chín bundled skill

Đây là các skill đóng gói sẵn — cùng cơ chế với skill bạn tự viết:

| Skill                       | Làm gì                                                                                                                               |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `/batch`                    | Điều phối thay đổi quy mô lớn song song                                                                                              |
| `/code-review`              | Review diff tìm lỗi đúng-sai và chỗ dọn được                                                                                         |
| `/claude-api`               | Nạp tài liệu tham chiếu Claude API và Managed Agents. Cũng tự kích hoạt khi code của bạn import `anthropic` hoặc `@anthropic-ai/sdk` |
| `/dataviz`                  | Hướng dẫn thiết kế biểu đồ và dashboard                                                                                              |
| `/debug`                    | Bật debug logging và gỡ rối sự cố runtime                                                                                            |
| `/doctor`                   | Kiểm tra thiết lập, chẩn đoán và sửa                                                                                                 |
| `/fewer-permission-prompts` | Quét transcript tìm các lệnh Bash và MCP read-only hay gặp, rồi thêm allowlist vào `.claude/settings.json` để bớt bị hỏi quyền       |
| `/loop`                     | Chạy lặp một prompt                                                                                                                  |
| `/verify`                   | Chạy test suite của project                                                                                                          |

Và một bundled workflow: `/deep-research`.

Hai skill trong nhóm này chỉ chạy **khi bạn gọi thẳng**, Claude không tự gọi: `/verify` và `/deep-research`.

`/fewer-permission-prompts` đáng chạy một lần sau vài tuần dùng — nó nhìn vào transcript thật của bạn để biết bạn hay bị hỏi cái gì, thay vì bắt bạn đoán.
